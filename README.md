# 確認して1通送信する

最新版Macアプリを起動し、会話を読み込んで本文を入力します。返信候補の「この候補を本文に使う」でも入力できます。「宛先・本文を確認」で送信先と送信元LINEアカウント、本文を確認し、「この内容で1通送信」を押した場合だけBeeperへ送信要求を出します。スマホ・別PCでも同じ流れです。Beeperトークンには書き込み権限が必要です。

確認は5分間有効です。送信直前にLINEの1対1トーク、送信元と会話の更新を再確認します。Beeperが返すpendingMessageIDは送信受付を意味し、相手のLINEへの到達を保証するものではありません。到達は実際のLINEで確認してください。

送信処理の開始記録をMacの `~/Library/Application Support/つながる営業/send-journal.sqlite3` に保存してから送信します。記録にはランダムな確認ID・状態・Beeperの受付ID・時刻だけを保存し、本文・Beeperトークンは保存しません。同じ確認IDは、再起動・二重クリック・ネットワークエラーでも再送しません。「送信結果を確認」は記録の参照のみで、新しく送信しません。結果が不明な場合はLINEで届いているか確認し、会話を読み込み直すまでは新しい送信をロックします。

新規環境では `supabase/remote-schema.sql` に続けて `supabase/confirmed-send.sql` を適用します。送信に未対応の旧Macアプリはクラウドの機能情報で判別します。自動送信・一斉送信・既読変更・LINE下書き変更には対応しません。

# スマホ・別PCから使う

1. Macで最新版の「つながる営業.app」を起動します。
2. 開いたMac内の画面の「スマホ・別PCから使うための設定」でメール・パスワードを入力し、「ログインしてこのMacを登録」を押します。
3. スマホ・別PCで https://line-per-line.netlify.app/ を開き、同じアカウントでログインします。
4. オンラインのMacを選び、「このMacのLINEを使う」→「LINE一覧を取得」を押します。

初回は公開サイトの「新規登録」からメール確認を完了してください。このSupabaseプロジェクトの既存メール・パスワードでもログインできます。登録確認メールのリンク先が別アプリの場合も、確認後にこのサイトへ戻ってログインできます。既存プロジェクトのAuth設定は変更していません。Macではリモート接続用のセッションを別途発行し、更新情報だけをMacのキーチェーンに保存します。スマホのログアウトはMacのセッションに影響しません。

Mac・Beeper・接続アプリ・返信生成時のOllamaは起動が必要です。Macの停止・スリープから約60秒以内にオフライン表示になります。ターミナル、VPN、ポート開放は不要です。Mac内の「このMacのリモート接続を解除」で停止できます。

## クラウドを経由する情報

ログインはSupabase Authを使い、専用の `line_remote_devices` と `line_remote_jobs` で本人だけのアクセスをRLSで制限します。Beeperトークンは引き続きMac内に保持します。トーク一覧、明示選択した最大20件の会話、返信候補はSupabaseを一時的に経由します。結果を取得すると削除し、未取得でも15分経過後の定期処理（1分間隔）で削除します。接続端末の識別情報は解除まで保存します。メール・パスワードはセッション確立時にAuthへ送信しますが、アプリではパスワードを保存しません。ブラウザのログイン情報はタブ内のsessionStorage、Macの更新トークンはキーチェーンに保存します。LINE本文はブラウザの永続保存領域に保存しません。

送信は確認画面で承認した1通だけです。既読・LINE下書き変更には対応していません。操作が4分以内に完了しない場合はタイムアウトとし、処理中の操作は自動再実行しません。

開発者向け: `supabase/remote-schema.sql` に追加スキーマ、`supabase/tests/remote_rls.sql` にロール別検証があります。公開設定の `public/cloud-config.json` にはpublishable keyのみを配置します。service-roleキーをWebやMacアプリに配置しないでください。

# ターミナル不要のMacアプリ

公開サイトの「Macアプリをダウンロード」からZIPを取得し、解凍した「つながる営業.app」を開きます。初回だけBeeperトークンを入力して保存・起動します。2回目以降はアプリを開くだけです。アプリの終了・ウィンドウを閉じる操作で接続も停止します。BeeperとOllamaは別途起動してください。旧版の接続アプリが起動中の場合は一度終了してください。

このビルドはApple Silicon搭載Mac向けです。Python 3.10以降が必要で、このMacには導入済みです。Apple Developer証明書による署名・公証は未実施です。別のMacでダウンロードしたアプリを開く場合、macOSのセキュリティ設定による確認が必要になる場合があります。

開発者向けビルド: `python3 build_macos.py --archive public/downloads/line-connector-mac.zip`。ビルドにはXcode Command Line Toolsが必要です。アプリには許可したソースファイルだけを同梱し、トークン・環境変数ファイルは含みません。

## Beeperトークンの自動読み込み

初回の起動でMacアプリの設定画面にBeeperトークンを入力すると、Macのログインキーチェーン（サービス名 `jp.line-per-sales.beeper`）に保存します。2回目以降は入力不要です。macOSがアクセス許可を求めた場合は内容を確認してください。トークンはソース・ZIP・GitHub・Netlify・ブラウザには含めません。環境変数 `BEEPER_ACCESS_TOKEN` を指定した場合は、その値を優先し、新たに保存しません。

入力を間違えた場合やトークン更新時は、アプリの「接続を停止」を押して新しいトークンを入力し、「保存して接続アプリを起動」を押すと入れ替えられます。「保存したトークンを削除」でキーチェーンから削除できます。Macのロック中などで読み込みを拒否された場合は、上書きせずエラーを表示します。

## 公開サイトからこのMacに接続

1. Macで「つながる営業.app」を開き、初回だけBeeperトークンをアプリ画面に入力して「保存して接続アプリを起動」を押します。
2. Mac内の画面で「公開サイト用の接続コードを発行」を押します。
3. https://line-per-line.netlify.app/ を同じMacのChromeで開き、接続コードを入力して「このMacへ接続」を押します。
4. ブラウザのデバイス接続許可が出た場合は許可し、「LINE一覧を取得」を押します。

Beeperトークンは公開サイトに入力しません。コードは5分・1回限り、5回失敗で無効です。公開サイトの接続は8時間またはアプリ停止まで有効で、タブの再読み込みでは失われます。Mac内の「公開サイトの接続を解除」から失効できます。会話は公開サイトのブラウザ画面で表示されますが、Netlifyサーバーへは送信しません。Mac・Beeper・接続アプリの起動が必要です。接続を許可する公開元は上記URLだけです。

# 個人LINE接続・営業デモ

## 個人LINE（Beeper経由・読み取り専用）

NetlifyのトップページからMac用接続版をダウンロードし、解凍後に「つながる営業.app」を開いてください。Apple Silicon搭載Mac・macOS 13以降・Python 3.10以降と、LINEを連携済みのBeeperが必要です。初回だけアプリ画面にBeeperアクセストークンを入力して起動すると、`http://127.0.0.1:8767` が開きます。トークンは初回入力時にMacのキーチェーンへ保存し、次回から自動で読み込みます。送信は確認画面で承認した本文のみです。既読・LINE側の下書き変更は行いません。

ターミナルからは `python3 app.py --personal --port 8767`。起動ファイルに実行権限がない場合は `chmod +x 個人LINE起動.command`。終了はControl + C。

1. 「LINE一覧を取得」で最大5件のLINEの1対1トークの相手名と更新日時を表示します。一覧APIの応答にはプレビュー・下書き本文が含まれる場合があります。ユーザーが許可した受信後の除外方式で、JSONの解析直後に必要なメタデータだけを残し、その他の項目を破棄します。画面・ログ・ファイル・AIへは渡しません。物理メモリのゼロ消去を保証するものではありません。
2. 相手を選択し「会話を読み込む」を押した場合にだけ、そのトークの最大20件のテキストを読み込みます。
3. 「返信候補を3案作る」を押すと、会話を再取得・確認してローカルOllamaへ渡します。Ollamaを起動し、`gemma3:4b` を用意してください（`ollama pull gemma3:4b`）。候補は実際の会話から生成します。

個人LINEの会話とトークンはNetlifyやGitHubに送信しません。Mac内だけの接続では会話をファイルやブラウザの保存領域に記録せず、BeeperトークンをMacの暗号化されたキーチェーンに保存します。クラウド接続の一時保存とログイン情報は上記を参照してください。候補を編集し、確認画面から送信できます。LINE下書き変更は行いません。会話の表示は一部の長文を省略します。営業案件と個人LINEの紐付け・商談ステータスの実データ化は、この版には含みません。

公開サイトのブラウザから、接続コードで許可したMac内の接続アプリへ通信します。Mac内のURLからも使用できます。Macを終了したりアプリを停止すると接続も終了します。公開サイトにトークン入力欄はありません。

実アカウントへの接続は手元のMacで確認してください。自動テストは架空のBeeper/Ollama応答を使い、初回の本文非取得、LINEだけの最大5件表示、会話の明示取得、ローカル生成、古い会話の拒否、確認なし送信の拒否、接続元の検証を確認します：`python3 -m unittest -v test_personal.py`。

## 架空データのデモ

架空の6顧客の営業一覧と、公式LINEを想定した返信候補を体験するデモです。Beeper・LINE・外部AIには接続せず、実送信はしません。返信候補は6シナリオ×3口調の定型文です。

## ローカル起動

Python 3で `python3 app.py` を実行し、表示されたURLを開いてください。Macでは `デモ起動.command` からも起動できます。終了はControl + C。追加パッケージ不要です。

## Netlify

このリポジトリを接続してください。ビルドコマンドは不要、公開ディレクトリは `public` です。`netlify.toml` に設定済みです。手動公開では `public` フォルダをアップロードします。トップは個人LINE接続の案内、架空データのデモは `/demo.html` です。

## 試せること

- 顧客・会社名の検索、商談ステータスの絞り込みと変更
- 顧客ごとの架空の会話と商談メモの確認
- 丁寧・親しみやすい・簡潔の返信候補の選択と編集
- 確認画面付きのデモ送信と架空の新着追加
- ブラウザ内への保存、デモの初期化

変更は各閲覧者のブラウザ内に保存され、他の閲覧者とは共有されません。実際の顧客情報は入力せず、架空データで試してください。
