## 公開サイトからこのMacに接続

1. Macで最新版の `個人LINE起動.command` を起動し、Beeperトークンをターミナルに入力します。
2. Mac内の画面で「公開サイト用の接続コードを発行」を押します。
3. https://line-per-line.netlify.app/ を同じMacのChromeで開き、接続コードを入力して「このMacへ接続」を押します。
4. ブラウザのデバイス接続許可が出た場合は許可し、「LINE一覧を取得」を押します。

Beeperトークンは公開サイトに入力しません。コードは5分・1回限り、5回失敗で無効です。公開サイトの接続は8時間またはアプリ停止まで有効で、タブの再読み込みでは失われます。Mac内の「公開サイトの接続を解除」から失効できます。会話は公開サイトのブラウザ画面で表示されますが、Netlifyサーバーへは送信しません。Mac・Beeper・接続アプリの起動が必要です。接続を許可する公開元は上記URLだけです。

# 個人LINE接続・営業デモ

## 個人LINE（Beeper経由・読み取り専用）

NetlifyのトップページからMac用接続版をダウンロードし、解凍後に `個人LINE起動.command` を開いてください。Python 3.10以降と、LINEを連携済みのBeeperが必要です。MacのターミナルにBeeperアクセストークンを入力すると、`http://127.0.0.1:8767` が開きます。トークンはメモリ内でのみ使用します。送信や既読・LINE側の下書き変更のAPIは実装していません。

ターミナルからは `python3 app.py --personal --port 8767`。起動ファイルに実行権限がない場合は `chmod +x 個人LINE起動.command`。終了はControl + C。

1. 「LINE一覧を取得」で最大5件のLINEの1対1トークの相手名と更新日時を表示します。一覧APIの応答にはプレビュー・下書き本文が含まれる場合があります。ユーザーが許可した受信後の除外方式で、JSONの解析直後に必要なメタデータだけを残し、その他の項目を破棄します。画面・ログ・ファイル・AIへは渡しません。物理メモリのゼロ消去を保証するものではありません。
2. 相手を選択し「会話を読み込む」を押した場合にだけ、そのトークの最大20件のテキストを読み込みます。
3. 「返信候補を3案作る」を押すと、会話を再取得・確認してローカルOllamaへ渡します。Ollamaを起動し、`gemma3:4b` を用意してください（`ollama pull gemma3:4b`）。候補は実際の会話から生成します。

個人LINEの会話とトークンはNetlifyやGitHubに送信せず、ディスクやブラウザの保存領域にも記録しません。候補の送信・コピー・LINE下書き変更は行いません。会話の表示は一部の長文を省略します。営業案件と個人LINEの紐付け・商談ステータスの実データ化は、この版には含みません。

公開サイトのブラウザから、接続コードで許可したMac内の接続アプリへ通信します。Mac内のURLからも使用できます。Macを終了したりアプリを停止すると接続も終了します。公開サイトにトークン入力欄はありません。

実アカウントへの接続は手元のMacで確認してください。自動テストは架空のBeeper/Ollama応答を使い、初回の本文非取得、LINEだけの最大5件表示、会話の明示取得、ローカル生成、古い会話の拒否、送信API不在、接続元の検証を確認します：`python3 -m unittest -v test_personal.py`。

## 架空データのデモ

架空の6顧客の営業一覧と、公式LINEを想定した返信候補を体験するデモです。Beeper・LINE・外部AIには接続せず、実送信はしません。返信候補は6シナリオ×3口調の定型文です。

## ローカル起動

Python 3で `python3 app.py` を実行し、表示されたURLを開いてください。Macでは `デモ起動.command` からも起動できます。終了はControl + C。追加パッケージ不要です。

## Netlify

このリポジトリを接続してください。ビルドコマンドは不要、公開ディレクトリは `public` です。`netlify.toml` に設定済みです。手動公開では `public` フォルダをアップロードします。トップは個人LINE接続の案内、架空データのデモは `/demo.html` です。

## 試せること

- 顧客・会社名の検索、商談ステータスの絞り込みと変更
- 顧客ごとの架空の会話と商談メモの確認
- 丁寧・親しみやすい・簡潔の返信候補の選択と編集
- 確認画面付きのデモ送信と架空の新着追加
- ブラウザ内への保存、デモの初期化

変更は各閲覧者のブラウザ内に保存され、他の閲覧者とは共有されません。実際の顧客情報は入力せず、架空データで試してください。
